## 🚀 البدء السريع

### الطريقة 1: فتح مباشرة
قم بفتح ملف `index.html` في متصفحك مباشرة.

### الطريقة 2: استخدام Local Server

**باستخدام Python 3:**
```bash
cd my-awesome-website
python -m http.server 8000
```
ثم افتح المتصفح وذهب إلى: `http://localhost:8000`

**باستخدام Node.js (http-server):**
```bash
npm install -g http-server
cd my-awesome-website
http-server
```
